# FairGRAPE 채널 프루닝 (impt_type==2) — 3가지 실험 설정 전 과정

> 채널 단위 φ_k 프루닝이 **여러 민감속성·태스크에서 공정성(EO)을 개선하는지 = 일반화되는지**
> 검증하기 위한 세 설정의 전체 파이프라인 정리.
> 모든 설정이 **같은 5단계**(① 성능점수 → ② φ_k 공정성점수 → ③ 결합·선택 → ④ 프루닝 → ⑤ 재학습)를
> 공유하며, 차이는 거의 전부 **② φ 계산(그룹 수·평균 대상·셀 크기)과 데이터의 편향 유형**에서 온다.

---

## 0. 용어 — 두 개의 축

| 축 | 뜻 | 코드 위치 |
|---|---|---|
| **Task (예측 대상)** | 모델이 맞혀야 하는 것 → 성능점수·φ의 gradient를 만든다 | `col_used[:-1]` |
| **Sensitive (민감속성)** | 그룹 간 공정성을 보는 기준 → φ의 격차를 만든다 | `col_used[-1]` (항상 마지막 열) |

라벨 텐서는 `[task…, sensitive]` 순서. `sensitive_a = label[:, -1]`로 민감속성을 꺼낸다.
그룹 수는 `main_test.experiment()`에서 `config.glo_n_groups`로 전역 전달된다.

## 경우 1 — 민감속성: **Gender** / Task: **얼굴 속성 39개** (CelebA)

**라벨 텐서**: `[attr₁, …, attr₃₉, gender]`, shape `[B, 40]`. 마지막 열(gender)이 민감속성 (2그룹).

| 항목 | 값 |
|---|---|
| 데이터셋 | CelebA (202,599장) |
| Task | 39개 얼굴 속성 각각 이진 |
| 민감속성 | Gender (0: 118,165 / 1: 84,434, 약 58:42) |
| `total_classes` | 78 (39×2) |
| `output_cols_each_task` | 39개 `[(0,2),(2,4),…]` |
| `col_used` | 39속성 + gender |
| `config.glo_n_groups` | 2 |
| 프루닝 | keep 0.9 (22 iter), **α 스윕 0.1~0.9** |

### ① 성능 점수 (compute_importance)
- 순전파 → **39개 태스크 손실의 합** `imp_loss = Σᵢ CE(속성ᵢ)` (`loss_multi_tasks`)
- 역전파로 각 레이어 가중치 gradient 획득
- 가중치별 중요도 = **`(|W|·|∇W|)²`** 를 배치마다 누적 → 레이어별 `importance_score`
- 이미 잘린 채널은 mask 곱해 0.

### ② φ_k 공정성 점수 (compute_phi_k)
- `num_attrs = 39`. 각 속성 y∈{0,1}마다:
  - 전 배치에 걸쳐 **(y, gender) 4개 셀**(2×2)의 활성 합·표본수 누적
  - 마지막에 그룹 평균의 `max−min` = **|남−여| 격차** (그룹 2개라 단순 절대차)
- 39개 속성의 격차를 **평균** → `activation_gap`
- **φ_k = (39속성 평균 gender격차) × mean|∂(39태스크손실)/∂a|**
- 셀 크기: 배치 64, gender 대략 반반 → 속성별 셀 ~16~32명 (희소 속성은 y=1 셀 1~2명 → 그 부분만 노이즈 큼). **세 경우 중 노이즈 가장 작음.**

### ③ 결합·선택 (fairness_grad)
- 채널별 성능(conv0+1+2 합산)과 φ를 각각 max로 정규화
- **combined = α·perf̂ − (1−α)·φ̂**, 여기서 **α를 0.1~0.9로 스윕**
- 보호구역: 각 레이어 perf 상위 0.5% 채널 후보 제외
- combined **오름차순 → 낮은 것부터** 선택 (성능엔 덜 중요 & 공정성 해치는 채널)
- 레이어 하한: 원본 채널 최소 3% 유지

### ④ 프루닝
- 선택 채널을 0으로 하는 마스크 생성·등록, forward/backward hook으로 항상 곱함
- 제거량 = **활성 가중치의 10%/iter** (keep 0.9) → **22 iter**에 90%

### ⑤ 재학습·평가
- iter당 재학습, best 모델 = **정확도 1순위**(EO는 동점 tie-breaker)
- EO = 속성마다 gender(2) TPR/FPR의 |남−여| → 39속성 평균
- **결과**: 90% 프루닝에 정확도 −4.6pt, **EO 0.174 → 0.117(α=0.3)** 단조 개선. ✅ 잘 붙음.

## 경우 2 — 민감속성: **Race** / Task: **Gender** (UTKFace)

**라벨 텐서**: `[gender, race]`, shape `[B, 2]`. 마지막 열(race)이 민감 (4그룹).

| 항목 | 값 |
|---|---|
| 데이터셋 | UTKFace (train 17,610) |
| Task | Gender 이진 |
| 민감속성 | Race 4그룹 (White 8,107 / Black 3,614 / Asian 2,738 / Indian 3,151) |
| `total_classes` | 2 |
| `output_cols_each_task` | 1개 `[(0,2)]` |
| `col_used` | `['gender','race']` |
| `config.glo_n_groups` | 4 |
| 프루닝 | keep 0.975 (91 iter), α=0.5 |

### ① 성능 점수 (compute_importance)
- 순전파 → **단일 태스크(gender) 손실** `CE(gender)`
- 역전파 → 가중치별 **`(|W|·|∇W|)²`** 누적 (경우 1과 동일하나 손실이 1개 태스크)

### ② φ_k 공정성 점수 (compute_phi_k)
- `num_attrs = 1` (gender). y∈{0,1}=남/여마다:
  - 전 배치에 걸쳐 **(y, race) 8개 셀**(2×4)의 활성 합·표본수 누적
  - 마지막에 **race 4그룹 평균의 max−min**
- **φ_k = (y=남 격차 + y=여 격차) × mean|∂(gender손실)/∂a|**
- 셀 크기: Asian 최소지만 gender는 y가 덜 치우쳐 **Asian 셀 ~10명/배치**.

### ③ 결합·선택 (fairness_grad)
- **combined = 0.5·perf̂ − 0.5·φ̂** (α=0.5 고정)
- 보호구역 0.5%, 오름차순 선택, 레이어 하한 3% (경우 1과 동일 로직)

### ④ 프루닝
- 마스크 생성·적용
- 제거량 = **2.5%/iter** (keep 0.975) → **91 iter**에 90%

### ⑤ 재학습·평가
- iter당 재학습, best = 정확도 1순위
- EO = **race 4그룹** TPR max−min + FPR max−min, 평균
- **결과**: baseline EO ≈ 0.066. race별 여성비율 0.43~0.54로 균등 → **인종 간 gender 격차가 거의 없음** → 줄일 편향이 없어 신호 없음. 부적합한 테스트베드.

## 경우 3 — 민감속성: **Race** / Task: **Age 이진** (UTKFace)

**라벨 텐서**: `[age_bin, race]`, shape `[B, 2]`. 마지막 열(race)이 민감 (4그룹).
`age_bin`은 `dataset.relabel`이 30세 기준(`AGE_BINARY_THRESHOLD=30`, 구간 하한 파싱)으로 생성.

| 항목 | 값 |
|---|---|
| 데이터셋 | UTKFace |
| Task | age_bin (30세 기준 이진) |
| 민감속성 | Race 4그룹 |
| `total_classes` | 2 |
| `output_cols_each_task` | 1개 `[(0,2)]` |
| `col_used` | `['age_bin','race']` |
| `config.glo_n_groups` | 4 |
| 프루닝 | keep 0.975 (91 iter), α=0.5 |

**라벨 분포 (핵심)**: 클래스 균형 양호 (old 9,109 / young 8,501). 그러나 race별 P(old) 크게 다름:

| race | White | Black | Asian | Indian |
|---|---|---|---|---|
| P(old) | 0.605 | 0.518 | **0.316** | 0.465 |
| (old, race) 표본 | 4,907 | 1,873 | **865** | 1,464 |

### ① 성능 점수 (compute_importance)
- 순전파 → **단일 태스크(age) 손실** `CE(age_bin)`
- 역전파 → 가중치별 **`(|W|·|∇W|)²`** 누적 (경우 2와 동일 구조, 태스크만 age)

### ② φ_k 공정성 점수 (compute_phi_k)
- `num_attrs = 1` (age). y∈{0,1}=young/old마다:
  - 전 배치에 걸쳐 **(y, race) 8개 셀**(2×4) 활성 합·표본수 누적
  - 마지막에 **race 4그룹 평균의 max−min**
- **φ_k = (y=young 격차 + y=old 격차) × mean|∂(age손실)/∂a|**
- 셀 크기(핵심): **Asian∧old가 배치당 ~3명** (train 865명). 수정 전 φ_k가 유령 격차에 가장 취약했던 경우. 수정으로 전 배치를 모아 한 번 max−min을 내면서 이 노이즈 제거.

### ③ 결합·선택 (fairness_grad)
- **combined = 0.5·perf̂ − 0.5·φ̂** (α=0.5 고정)
- 보호구역 0.5%, 오름차순 선택, 레이어 하한 3%
- 한계: race와 age가 데이터상 상관(base-rate 차이) → **인종 구분 채널 = 나이 구분 채널** → φ와 perf가 얽혀 분리 어려움.

### ④ 프루닝
- 마스크 생성·적용
- 제거량 = **2.5%/iter** (keep 0.975) → **91 iter**에 90%. 단일 이진 태스크라 중복 적어 **~40% 제거에서 정확도 절벽**.

### ⑤ 재학습·평가
- iter당 재학습, best = 정확도 1순위 → **정확도 최대화가 base-rate 편향("Asian→young")을 되살림**
- EO = **race 4그룹** TPR max−min + FPR max−min, 평균
- **결과 (φ_k 수정 후, 옛 코드와 공정 비교)**: 정확도는 비슷~약간 손해, **후반(41~55 iter) EO 0.222→0.171 개선**. 단 개선폭이 노이즈 바닥(~0.08~0.12) 규모라 시드 재현 확인 필요.

## 연구 관점 — 왜 이 셋인가

세 경우는 φ_k가 **"언제" 공정성을 개선하는지**를 가르는 세 축을 각각 건드린다:

1. **경우 1 vs 2·3 — 태스크 수(채널 중복)**: φ_k가 성능 보존과 공정성 개선을 동시에 하려면
   "공정성은 해치지만 성능엔 없어도 되는" 여유 채널이 있어야 한다. 멀티태스크(39)인 경우 1엔 있고,
   단일 이진 태스크인 경우 2·3엔 적다.
2. **경우 2 vs 3 — 편향의 존재/유형**: 같은 UTKFace·race인데 경우 2는 편향이 거의 없고(신호 없음),
   경우 3은 편향이 있으나 **base-rate형**이라 채널로 안 잡힌다.
3. **그룹 수(2 vs 4) + 소표본**: max−min EO의 노이즈 취약성. 경우 3의 Asian∧old(배치당 3명)에서
   수정 전 φ_k 버그가 가장 크게 작동했다.

**잠정 결론**: φ_k는 **편향이 채널에 국소화돼 있고(표현형) & 자를 여유 채널이 있는(멀티태스크)** 경우(경우 1)에
붙고, **base-rate 편향 + 단일 태스크**(경우 3)에선 구조적으로 어렵다.

### 미해결/후속 (별도 이슈)
- φ의 gradient 항에 그룹 정보 부재 → φ가 성능 saliency와 구조적으로 얽힘
- 격차 미표준화(효과크기 아님), `scale_score_tensor`의 max 나누기(heavy-tail 뭉갬)
- 노이즈 바닥(permutation null)로 EO 변화의 유의성 검정 필요
- random/perf-only 대조 프루닝으로 φ_k 기여 귀속 필요
- 재학습이 정확도 1순위라 base-rate 편향 복원 → EO-aware 재학습 또는 무재학습 ΔEO로 순수 효과 분리
